Explora grafos de Sudokus

Cada nodo representa una solución de Sudoku (N×N) y las aristas codifican relaciones definidas por tus reglas de adyacencia. Usa los lienzos para comparar distintos grafos o reglas.

Cómo funciona

Los grafos se cargan desde un archivo JSON que contiene, para cada tamaño de Sudoku N:

  • N: tamaño del Sudoku.
  • labels: vector de etiquetas de longitud N².
  • graphs: lista de grafos, cada uno con su matriz de adyacencia N²×N².

El código valida que las matrices de adyacencia y el vector de etiquetas tienen las dimensiones correctas antes de dibujar nada.

Lienzos de grafos

Usa el panel lateral para crear múltiples lienzos. Cada uno puede mostrar un grafo diferente (por ejemplo, otra regla de adyacencia o tamaño de Sudoku) y así comparar sus propiedades visualmente.
